# NK Enterprises Digital — GitHub Pages

A responsive static website starter for NK Enterprises Digital. It uses only HTML, CSS, and a tiny inline script; no build tools or paid hosting are required.

## Publish with GitHub Pages

1. Create a **public** repository named `nkenterprisesdigital` on GitHub.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then click **Save**.
6. Wait a few minutes. The URL will normally be `https://YOUR-USERNAME.github.io/nkenterprisesdigital/`.

## Before publishing

- Review the services and wording to ensure they accurately describe what you offer.
- Confirm the email and WhatsApp details.
- Replace the illustrative dashboard and service descriptions if you want a closer match to your Google Sites design.

## Notes

- This is a recreated static site, not a direct export of Google Sites.
- The email link opens the visitor's email app; the WhatsApp link opens a chat.
- Contact form backend, analytics, custom domain, and logo assets are not included.
